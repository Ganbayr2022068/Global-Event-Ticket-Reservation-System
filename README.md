# Global Event Ticket Reservation System

## About the Project

The Global Event Ticket Reservation System is a system for finding and reserving tickets for different events around the world.

Users can search for events, check event information, select tickets, and make reservations online.

## Main Users

* Customers
* Event Organizers
* System Administrators

## Main Features

* User Registration and Login
* Event Search
* Event Filter
* Event Details
* Ticket Selection
* Online Payment
* Digital Ticket
* Reservation Management
* Event Management
* User Management
